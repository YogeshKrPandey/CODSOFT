# Task 3 - Contact Book
**CodSoft Python Internship**

A simple Python-based Contact Book that allows users to add, view, search, and delete contacts.  
Contact details are saved in a text file for persistence between sessions.

## Features
- Add new contacts with name, phone, email, and address  
- View all saved contacts  
- Search contacts by name or phone number  
- Delete specific contacts  
- Data saved in `contacts.csv`
